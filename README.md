# Ziggy Moens - Digital Innovation Portfolio

A modern, responsive portfolio website showcasing Ziggy Moens' expertise in digital transformation, technology consulting, and innovation.

## 🚀 Features

- **Modern Design**: Clean, contemporary design with smooth animations
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Elements**: Smooth scrolling, hover effects, and scroll-triggered animations
- **Performance Optimized**: Fast loading with optimized assets and modern JavaScript
- **Accessibility**: Built with accessibility best practices in mind

## 🎨 Design Highlights

- **CSS Grid & Flexbox**: Modern layout techniques for responsive design
- **CSS Custom Properties**: Consistent theming with CSS variables
- **Smooth Animations**: CSS transitions and JavaScript-powered animations
- **Modern Typography**: Inter font family for excellent readability
- **Gradient Accents**: Subtle gradients for visual interest

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern CSS with Grid, Flexbox, and Custom Properties
- **JavaScript (ES6+)**: Modern JavaScript with Intersection Observer API
- **Font Awesome 6**: Latest icon library
- **Google Fonts**: Inter and JetBrains Mono fonts

## 📱 Sections

1. **Hero Section**: Eye-catching introduction with profile image
2. **About**: Professional summary and expertise overview
3. **Experience**: Comprehensive timeline of professional experience
4. **Education**: Academic background and professional certifications
5. **Expertise**: Core skills and technology areas
6. **Contact**: Multiple ways to connect professionally

## 🔧 Setup & Development

1. Clone the repository
2. Open `index.html` in your browser
3. All assets are included in the `assets/` folder
